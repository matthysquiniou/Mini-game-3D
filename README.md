# Mini Game Project – One Week Development

## Installation and Solution Generation

1. Go to the `bin/` folder.  
2. Run `make.bat`.  
3. The script will generate an `ide/` folder containing `[SOLUTION_NAME].sln`.  
4. Open the Visual Studio solution.  

Project completed in **1 week** as part of a school assignment.  
Here you will find **three playable mini-games**, developed using a **simplified version of GCE** (Gaming Campus Engine).

---

## Included Games

### 1. Ball Catcher  
A skill-based game focused on catching falling objects.

**Controls:**
- **D** → move right  
- **Q** → move left  

**Goal:**  
Catch as many items as possible without letting them fall.

---

### 2. Shuffle Puck  
A game inspired by air hockey / shuffleboard.

**Controls:**
- **Mouse** → control the puck / striker

**Goal:**  
Guide the puck accurately to reach the target area.

---

### 3. Tron  
A “light cycle” style game inspired by Tron.

**Controls:**
- **D** → turn right  
- **Q** → turn left  

**Goal:**  
Survive as long as possible without hitting walls or your own trail.

---

## ⏸ Pause

In **all games**:
- **Escape (ESC)** → pause the game

---

## 🛠 Technology Used

- **Engine:** Simplified version of **GCE (Gaming Campus Engine)**  
- Learning-focused project covering gameplay logic, input handling, game loop structure, collisions, and game states (pause, play, etc.)

---

## Educational Purpose

The objectives of this project were to:
- Understand the basics of a 3D game  
- Implement simple gameplay mechanics  
- Manage a short project containing multiple playable games
