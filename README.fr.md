# Mini-projet Jeux – Semaine de développement

## Installation et génération de la solution

1. Aller dans le dossier `bin/`.
2. Exécuter `make.bat`.  
3. Le script génère un dossier `ide/` contenant `[SOLUTION_NAME].sln`.
4. Ouvrir la solution Visual Studio.

Projet réalisé en **1 semaine** dans le cadre d’un travail scolaire.  
Vous trouverez ici **trois mini-jeux jouables**, développés avec une **version simplifiée du GCE** (Game Engine du Gaming Campus).

---

## Jeux inclus

### 1. Ball Catcher  
Jeu d’adresse basé sur la récupération d’objets.

**Contrôles :**
- **D** → déplacer à droite  
- **Q** → déplacer à gauche  

**Objectif :**  
Attraper un maximum d’éléments sans les laisser tomber.

---

### 2. Shuffle Puck  
Jeu inspiré du air hockey / shuffleboard.

**Contrôles :**
- **Souris** → contrôler le palet / le striker

**Objectif :**  
Diriger le palet avec précision pour atteindre la zone cible.

---

### 3. Tron  
Jeu de type “light cycle” inspiré de Tron.

**Contrôles :**
- **D** → tourner à droite  
- **Q** → tourner à gauche  

**Objectif :**  
Survivre le plus longtemps possible sans percuter les murs ou sa propre trace.

---

## ⏸ Pause

Dans **tous les jeux** :
- **Échap (ESC)** → mettre le jeu en pause

---

## 🛠 Technologie utilisée

- **Moteur :** Version simplifiée du **GCE (Gaming Campus Engine)**  
- Projet orienté apprentissage : logique de gameplay, gestion d’input, boucle de jeu, collisions, et états (pause, jeu, etc.)

---

## Contexte pédagogique

Ce projet avait pour but de :
- Comprendre les bases d'un jeu en 3D
- Implémenter des mécaniques de gameplay simples  
- Organiser un projet court avec plusieurs jeux jouables
